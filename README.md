### 🧭 About me

I spent my early career in banking (Bank Negara Malaysia, then CIMB). These days I build small, useful, dependency-light tools and care about **self-hosting**, **FreeBSD**, **retro-game preservation**, **email security**, and **local AI**. I like software that does one thing well, ships in a single file, and runs on whatever server I already have.

- 🏠 Based in Kuala Lumpur, Malaysia
- 🐡 FreeBSD advocate - I run [freebsd.my](https://freebsd.my)
- 🕹️ I patch old RTS games so they run on modern Windows
- 📦 I prefer single-file, no-database, no-build tools
